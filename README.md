# ATN Clientes Toyo Foods

## Uso en GitHub Desktop / GitHub Pages
1. Descomprime este ZIP.
2. Sube los archivos `index.html` y `data.js` a tu repositorio.
3. Publica con GitHub Pages.
4. Abre el enlace del sitio.

## Importante
- No borres `data.js`: ahí está la base de clientes y productos.
- El correo automático desde GitHub Pages no se puede enviar directo sin servicio externo. Esta versión abre el correo/WhatsApp ya armado.
- Para envío automático real se recomienda conectar Formspree, EmailJS, Google Forms o Supabase.
